Always available

Esc　　one step back (let go, close a window, cancel)

U　　　undo (as many times as you like)

Tab　　re-pick among overlapping objects / cycle snap candidates

E, Delete　erase the selection

Space　hold it and drag with the left button = pan

Function keys

F5　　rotate the isometric face (left, top, right)

F8　　ortho on/off (Shift = reversed while held)

⌘ (Command)　※ on Windows this is Ctrl

⌘A　　select all　　⌘⇧A　deselect all

⌘C　　copy　　⌘X　　cut

⌘V　　paste (click where it goes)

⌘⇧V　paste at the coordinates it was copied from

⌘Z　　undo (the same job as U)

⌘S　　save　　⌘⇧S　save as

⌘O　　open (DXF, DWG, PDF, JWW, STL)

⌘N, ⌘T　a new drawing tab

⌘P　　export to PDF

⌘K　　the Alias board (see below)

The Alias board: change the ⌘ shortcuts to suit your own fingers

Open it from エイリアス (Alias) on the ribbon, 鍵 or KEYS in the Command Line, or ⌘K.

Every ⌘ shortcut above can be changed on this board.

  1. ①
    Click the row you want to change.
  2. ②
    Press the new shortcut just as you would use it (⌘⇧C, say). A shortcut you cannot press can also be entered by clicking the keyboard map.
  3. ③
    If somebody already holds that shortcut, it is refused on the spot and you are told whose it is: “そのキーは○○が使っています” (that key belongs to ○○).
  • The keyboard map on the board shows the current owners in colour: blue = somebody's shortcut / orange = a letter used by a single-key tool / pale = free. The ⌘, ⌘⇧ and ⌘⌥ toggles above it change which layer you are looking at.
  • 既定 (Default) at the right of a row restores the factory shortcut; 外す (Clear) leaves it with none. (Even with no shortcut, the ribbon and the Command Line still reach it as before.)
  • One job can hold up to two shortcuts (⌘N and ⌘T, for instance).

⚠️ L, C, A, D, O, U, E and F8 are single-key tools and lie outside this board (they cannot be changed).

⚠️ Punctuation keys (, . / [ ] and so on) cannot be used as shortcuts. Depending on the keyboard layout, the printed character and the physical position do not match.

The habits of Enter

  • An empty Enter sometimes means “carry on as you are” (accepting a row of dimensions, running a unit scale, keeping the last text height, and so on).
  • An empty Enter sometimes means “cancel” (when typing a name or a piece of text). The prompt beside the cursor tells you which it is, each time.

Only in the 3D room

Drag with the left button, or the arrow keys = rotate

1–5 = top, front, right, left, back　　0 = isometric

PageUp / PageDown = raise or lower the extrusion height. Esc = back to the drawing.
