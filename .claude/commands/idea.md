施主（博喜さん）が iPhone から思いつきを預けます。**ここでは実装しません。**

預かるもの：
$ARGUMENTS

## やること

1. リポジトリ直下の `申し送り.md` を読む。無ければ、この形で作る。
2. 日付を `date +%Y-%m-%d` で取る。**推測で書かない。**
3. 「## 未処理」の**直下**（＝先頭）に足す。新しいものが上に来るようにする。

   ```
   ### YYYY-MM-DD　<10〜20字の見出し>
   （iPhoneから）
   <預かった言葉を、要約せずそのまま>
   ```

   会話の流れで補える前提があれば `前提：` として1〜2行だけ足す。
   Macの側で最初に確かめるとよいことが分かるなら `確かめること：` として足す。
   **どちらも思いついたときだけ。無理に埋めない。**

4. **言い換えて整えない。** 短い言葉なら、そのまま置く。
   思いつきは、言い回しの中に理由が入っていることがあります。整えると理由ごと消えます。

5. `git add 申し送り.md` → commit → `git push -u origin <いまのブランチ>`。
   コミットメッセージは `申し送り：<見出し>` の一行のあと、預かった言葉の要旨。

6. 施主へは短く返す。**何を預かったか**と、**Macで `/todo` と打てば出てくること**だけ。

## やらないこと

- **コードを書かない。ファイルを直さない。** 画面が小さく、動かして確かめる手立てがありません。
  ここは思いつきを落とさないための場所で、**考える場所でも作る場所でもありません。**
- **調べ物に長く潜らない。** 一言二言で答えられることなら答えてよいが、
  読み込みが要ると分かったら、それも含めて預ける。
- **「それは難しいです」と評価しない。** 預かるのが仕事です。
  ただし例外がひとつ。**すでに済んでいること**なら、「済」の欄を指して一行だけ伝える。
  同じものを二度積まないため。

## 相談したいだけのときは

`/idea` を使わず、そのまま話してください。話しているうちに「これは残す」と決まったら、
そのときに `/idea` と打てば足ります。**全部を帳面に載せる必要はありません。**
