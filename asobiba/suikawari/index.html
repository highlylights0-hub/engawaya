スイカわり

目をつかわないで あそべます

音をたよりに、スイカをさがして、わる遊びです。

スイカわりは、もともと目かくしでやる遊びです。 だからこのゲームは、目の見える人も見えない人も、おなじルールで遊びます。

まわりのみんなが「もうちょっと みぎ！」「ちかいよ！」と声をかけてくれます。 その声をたよりに歩いて、ここだと思ったら、わってください。

音と声が出ます。音量をたしかめてから、下の「あそぶ」を押してください。 いそがなくて大丈夫。時間制限はありません。

あるいた 0 ぽ ふった 0 かい さいこう - ぽ
こえの出どころ（読み上げソフトをお使いの方は「まかせる」へ）
こたえの地図（付きそいの人が見るためのもの）

あそびかた

  • スイカは、どこか近くの地面にあります。場所は毎回かわります。
  • ボタンは4つ。「ひだりをむく」「みぎをむく」「すすむ」、そして「えいっ！（わる）」。
  • むきを変えたり歩いたりするたびに、みんなが声で教えてくれます。
  • イヤホンで聞くと、音のする方向でも分かります（なくても遊べます）。
  • キーボードなら、ひだり・みぎ・うえの矢印キーと、スペースキー（わる）でも遊べます。
  • 読み上げソフト（VoiceOver・NVDAなど）でも遊べます。二重にしゃべってしまうときは、設定の「こえの出どころ」を「よみあげソフトにまかせる」にしてください。
スイカわりは開発中の遊びです。おかしいところがあれば 縁側屋の連絡先まで教えてください。ひとつずつ直します。
